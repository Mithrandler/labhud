Setup code

LabHUD printed it in its log when it started: docker logs labhud (or the terminal you started it in). Only someone who can read that log can set LabHUD up.

Proxmox VE

LabHUD reads Proxmox with an API token that can only read. Create one on any node's shell:

pveum user add labhud@pve
pveum aclmod / -user labhud@pve -role PVEAuditor
pveum user token add labhud@pve wall --privsep 0

Or in the web UI: Datacenter › Permissions › API Tokens › Add, then give the token the role PVEAuditor on /.

What to show

Every node gets a card with its CPU, RAM and disk. Choose the guests that get a card of their own.

Other services

Open one, fill it in and press Try: LabHUD asks the service once with those values, and keeps them only if that works. Each one becomes a card on the first page.

Find servicesOptional: LabHUD asks the hosts you list on the usual ports of the services below, and recognises each by its answer.

The display

Exactly as typed in its browser, with the port. Anything else gets 421: this stops a web page in the display's browser from reading LabHUD through a name of its own (DNS rebinding).

The admin

One account guards pairing phones (the LabHUD app) and opening the config editor from the display: a password, plus a code from an authenticator app on your phone (Aegis, 2FAS, Bitwarden, Google Authenticator…).
